# SmokeSpot 개발 연혁 — 실제 로컬판의 변화

> 이 문서는 2026년 10월부터 이어진 **로컬 개발 버전**을 초기 HTML, 이전 README, 검증·수정 기록에 기초해 **사후 복원**한 것입니다. 모든 버전의 소스가 현재 Public 저장소에 존재한다는 뜻이 아니며, 버전 번호를 예전 Git 커밋처럼 꾸미지 않습니다. 날짜가 불분명한 버전에는 임의 날짜를 붙이지 않았습니다. **2026-11-14 기준 최신 로컬판은 v3.7.41.18**입니다.

## 개발 이정표

| 버전·단계 | 당시 실제로 집중한 변화 | 얻은 교훈·남은 과제 |
|---|---|---|
| 문제 정의 (2026년 10월) | '흡연공간이 부족하다'에서 '어디에 설치하면 주변 불편을 줄일 수 있는가'로 문제 설정 | 흡연자 접근성과 비흡연자 보호는 함께 고려해야 하지만, 서로 같은 지표가 아님 |
| v0.8 | 카카오 지도에 학교·공원 표시, 학교 30m 자체 참고영역과 약 500m 분석 반경 | 보호시설에 가까운 곳을 시각화할 필요. 당시 학교 경계는 지금의 사용자 검토 경계와 다름 |
| v0.9 | 검색한 놀이터의 경계를 사용자가 직접 그림; 자체 3m 여유영역 | 위치 점 하나만으로는 실제 시설 범위를 표현하기 어려움 |
| v1.x | 지역 현황·공간정보·인구 자료 결합 실험 | 각 출처의 공간 기준·정확도·사용조건을 구분해야 함 |
| v2.2~v2.3 | 인구를 참고한 자동 탐색, 수동 위치 조정, 건물 인접 조건 검토 | 추천된 점과 실제 현장에서 검토할 점은 다를 수 있음 |
| v2.5 | 보도 내부 후보 자동 제외 선택 | 비어 보이는 지도가 곧 설치 가능한 부지는 아님 |
| v2.6 | 하천 도형·경계 15m 자체 주의 기준 추가 | 내부 주의 기준을 법적 금지거리처럼 표현하면 안 됨 |
| v2.8~v2.9 | 토지피복 분류·검토 근거 및 주의/미확인 구분 | 분류 정보는 토지 소유권·설치 허가를 증명하지 않음 |
| v3.1~v3.2 | 지도 중심의 후보지 검토 및 저장 흐름 정리 | 분석 결과는 조작 가능한 화면에서 검토되어야 함 |
| v3.3 | 학교 정보 출처 및 자체 참고영역 재검토 | 과거 150m 원형 참고 범위는 법정 금연구역이 아님 |
| v3.4 | 후보 2~3곳 비교, CSV 출력 | 단일 최고 점수보다 조건별 비교가 유용함 |
| v3.5 | 관점별 가중치와 점수 우선/권역 분산 비교 | 관점이 달라지면 좋은 후보의 의미도 달라짐 |
| v3.6 계열 | 지도 중심 UI·저장 조사지점·상세 비교, 스크롤과 표시 오류 수정 | 저장한 지점과 자동 추천 지점은 구별해야 함 |
| v3.7.0 | 점수 기여 근거 시각화, 점수 우선 모드의 숨은 120m 간격 제한 제거 | 화면 이름과 실제 선택 로직이 일치해야 함 |
| v3.7.15~v3.7.16 | 저장 지점 일괄평가·자동 후보 목록 갱신 오류 수정 시도 | 당시 일부 수정은 회귀 검증 전이었으며 이후 계속 개발됨 |
| v3.7.2x~v3.7.3x | 초기 500m 중심 추천에서 섹터/선택 영역 기반 탐색으로 변화; 보호점수의 구성과 설명 정리 | 넓은 지역의 최고점 몇 개보다, 사용자가 관심 지역을 지정해 판단하는 방식이 유용함 |
| v3.7.37~v3.7.39 | 건물/보도 이격·인구를 결합한 보호점수, 고정거리 평가/지역 비교 반영, 요소 진단 | 지역 상대 비교와 고정 기준을 혼동하지 않도록 설명 필요 |
| v3.7.40~v3.7.41 | M1/M2와 주거인구 공개율 80%↔50% 민감도, 결측 처리, 사용자 평가 설정 | 점수가 계산되지 않는 것과 점수가 낮은 것은 다름 |
| v3.7.41.4~v3.7.41.13 | 보호시설 경계 가까움 최대 10점 감점, 설정 UI, 가독성·표시·오류 수정 | 법적 제외 조건과 자체 참고 감점은 독립돼야 함 |
| v3.7.41.14~v3.7.41.18 | 세 관점 사용자 배점 기준선·초기화, 슬라이더 정렬, 화면 최종 정돈 | 사용자가 기준값을 바꾸고 비교할 수 있어야 함 |

※ 개별 세부 기능의 정확한 도입 버전이 연속해서 검증되지 않은 v1~v2 계열과 일부 v3.7 구간은 **범위로만 표기**했습니다.

## 개발하면서 바뀐 가장 큰 생각

**처음:** 적절한 시설 후보지를 몇 곳 자동으로 추천하면 문제를 해결할 수 있다고 생각했습니다.

**지금:** 입지 분석은 정답을 뽑는 것보다, 왜 그 위치가 후보인지와 무엇을 확인하지 못했는지를 명확히 보여주는 일이 중요합니다. 보호점수는 비흡연자 노출 가능성을 간접적으로 판단하는 수단이지 설치 결정을 대신하는 최종 수치가 아닙니다.
