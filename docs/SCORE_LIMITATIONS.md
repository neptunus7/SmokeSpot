# 점수 체계 검토 및 한계

## 현재 모델의 역할

SmokeSpot 보호점수 P는 주변 건물·보도와의 거리 및 인구 지표를 바탕으로 **비흡연자 보호에 유리해 보이는 공간적 조건**을 비교하기 위한 실험 지표다. 최적 입지, 실제 연기 노출, 합법성, 이용 가능성, 시설 설치 허가를 뜻하지 않는다.

## 현재 포팅된 기본 수식

- 건물 이격 `W = min(1, 건물과의 거리 / 50)`
- 보도 이격 `F = min(1, 보도와의 거리 / 25)`
- 주거인구 역정규화 `R = clip((Q90 - 주변인구지표) / (Q90 - Q10), 0, 1)`
- 생활인구 역정규화 `L = clip((Q90 - 생활인구지표) / (Q90 - Q10), 0, 1)`
- 기본 보호점수 `P = 35W + 25F + 25R + 15L`

숫자 50·25, 점수대 경계, 가중치, Q10/Q90은 임시 실험 기준이다. 법적 안전거리나 건강상 위험 기준이 아니다.

## 설계상 중요한 한계

1. **실제 이용 수요 누락:** 인구가 적고 건물·보도와 멀면 높은 점수를 얻을 수 있지만, 이용자가 접근하기 어려운 장소일 수 있다. P 단독으로 '최적 입지'를 확정하지 않는다.
2. **인구자료 누락/편향:** 일부 100m 인구 격자가 비공개 또는 미수록이면 공개된 격자만으로 계산한 가중평균이 전체 지역을 대표하지 않을 수 있다. 자료가 없는 격자를 0명으로 간주하지 않는다.
3. **격자 크기의 한계:** 100m/250m 인구를 사용하므로 같은 격자 내부의 건물·도로·교량·보행 위치별 인구 분포를 정확히 알 수 없다.
4. **이격거리만으로 노출 판단 불가:** 보행자 수, 보행 경로, 실제 바람·연기, 출입구·환기구 등을 모델이 측정하지 않는다.
5. **시설 유형과 관리 미반영:** 재떨이와 개방형·밀폐형 부스의 효과, 설치비, 관리인력, 토지소유권, 행정승인은 별도 검토가 필요하다.
6. **탐색 영역의 영향:** 혼합 P의 상대 이격 기준은 최초 탐색 영역에서 구한 기준이므로 서로 다른 영역의 점수를 직접 비교할 수 없다.
7. **낮은 공개율 실험:** 로컬 v3.7.40~3.7.41에서는 조사 지점의 최소 공개율을 기존 80%에서 50%까지 완화해 민감도를 시험했다. 50%가 통계적으로 최적이라는 검증은 없고, 일부 자동 추천과 조사/섹터 간 기준이 서로 다를 수 있다.

## 사용자가 이해하기 쉬운 표현

- '공간 중첩' 대신: **'주변 건물·도로와 겹칠 수 있어요'**
- '가상 지름 4m 영역 중첩' 대신: **'가정한 설치 공간이 주변 시설과 겹쳐요'**
- '결측' 대신: **'인구 자료가 부족해요'**
- '미산정' 대신: **'점수를 계산하지 못했어요 (0점이 아님)'**

## 공개 데모와 로컬 실험의 구분

이 공개 데모의 데이터는 전부 합성 자료다. M1/M2 사진·좌표·면담 원문 및 실데이터 기반 점수는 포함하지 않는다. 현장 검증 결과는 별도 제출 자료에서 데이터 공개조건·초상권·면담 동의 등을 확인한 뒤 사용한다.
