# 다음으로 논의할 문제 — 해결했다고 주장하지 않는 질문들

SmokeSpot의 현재 목표는 한 번에 '정답 위치'를 확정하는 것이 아니라 **비흡연자 보호를 우선하면서도 실제로 이용 가능한 흡연 공간을 검토할 근거를 정리하는 것**입니다.

## 평가 모델

1. 현재 보호점수는 비흡연자 노출 가능성을 간접 지표로 비교합니다. 흡연자의 접근성과 실제 이용 수요는 **별도 축**이 필요할까요?
2. 주거인구 100m·생활인구 250m의 격자 크기·측정 시점 차이를 어떻게 보정하고 명확히 전달할까요?
3. 자료가 부족한 곳을 미산정으로 두는 것과, 공개율·신뢰도 지표를 보여주는 방법 중 무엇이 더 적절할까요?
4. 생활인구의 하루 평균과 특정 시간대가 후보 순위에 얼마나 영향을 미칠까요?
5. 통학 가능 경로, 출입구·환기구, 보행 흐름을 실제 측정 없이 어떻게 다뤄야 할까요?

## 실제 시설과 적용

1. 재떨이만 있는 간이 위치, 반개방형, 밀폐형 부스의 보호 효과를 같은 점수로 취급할 수 있을까요?
2. 실제 사용 가능한 부지인지 확인하기 위해 설치 주체·소유권·유지관리·민원 요소를 무엇부터 점검해야 할까요?
3. M1/M2와 같은 실제 현장 관찰에서 얻은 정보가 자동점수와 다를 때, 어떻게 분석 모델을 수정해야 할까요?
4. 지자체에 제안할 때 후보 위치뿐 아니라 **데이터 공백·미확인 법률 조건·실험적 가중치**를 어떻게 설명할까요?

## 공개·검증

1. 실제 좌표/인구 데이터와 무관한 코드·테스트를 어디까지 추가 공개할 수 있을까요?
2. 외부 데이터 재배포 조건이 확인되지 않은 경우에도 시연과 기술 설명을 충분히 제공할 수 있을까요?
3. 나중에 현장 사진을 공개하려면 당사자 동의와 위치 비식별 처리가 무엇이 필요할까요?

현재 공개 데모는 가상 데이터를 사용하는 제한된 기능 시연이며, 위 문제들이 해결됐다고 주장하지 않습니다.
