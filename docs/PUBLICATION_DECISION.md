# 개발본과 공개 시연을 분리한 이유 (2026-11-15 현재 상태 정정)

## 현재 공개 상태

- **로컬 개발본:** v3.7.41.18의 통합 분석 환경과 여러 기관 자료·현장조사 기록을 포함합니다. 모든 내부 데이터와 원본 파일을 공개한 것은 아닙니다.
- **기본 데모(`/`):** 실제 장소와 연결되지 않은 가상 도형·가상 인구로 섹터 분석의 개념을 설명하는 독립 시연입니다.
- **중계동 지도 시험판(`/preview/`):** 실제 카카오 지도와 일부 실제 위치에 대응하는 시설·참고 경계, 사용자 수동 등록 경계를 사용합니다. **표시 인구는 가상**입니다. `preview/public_playgrounds.geojson` 등에는 실제 좌표가 포함될 수 있습니다.
- **대표 공개 링크:** README는 `/preview/`를 중심으로 안내합니다. 기본 가상 데모는 개발 기록과 테스트용으로 남겨둡니다.

## 공개 범위의 원칙

사용 가능한 데이터라는 사실이 곧 **가공 좌표·원본 파일의 공개 재배포 허용**을 의미하지는 않을 수 있습니다. 기관별 출처·저작물 이용허락·API 이용 조건·지도 이미지 이용 조건을 따로 확인해야 합니다. 일부 출처 표기 후 이용 가능 회신은 받았지만, 모든 자료의 재배포 권리를 확인했다는 뜻은 아닙니다. 미회신도 허가 또는 금지 판정으로 해석하지 않습니다.

일부 로컬 HTML에는 실제 도형 좌표가 직접 포함될 수 있어서 JSON 파일만 제거해서는 공개 권한 문제가 모두 해결되지 않습니다. 공개 시험판은 원본 전체를 공개하는 대신 일부 참고 도형과 사용자 작성 경계를 시연하는 별도 구성입니다. 그러나 **현재 시험판에 실제 좌표가 공개돼 있으므로**, 파일마다 적절한 공개 권한과 출처를 확인하고 필요한 경우 해당 파일을 보류하거나 대체해야 합니다.

## 민감 자료와 인증정보

- 기관 원본의 재배포가 미확인된 지적·학교 부지·절대보호 도형 및 비공개 인구 원본을 임의로 업로드하지 않습니다.
- 현장 기록의 자세한 진술·사진·개인 정보는 별도 검토합니다. README에 사용한 지도 캡처에는 M1·M2의 대략적 위치가 시각적으로 나타날 수 있습니다.
- 공개 웹 지도용 **카카오 JavaScript 앱 키**는 브라우저에서 확인 가능한 성격이므로 개발자 콘솔에서 사용 도메인 제한을 점검합니다. REST/Admin 키·비밀 환경 파일은 공개하지 않습니다.
- 점수, 위치, 경계는 확정 금연구역·시설 설치 허가·실제 간접흡연 노출의 측정 결과로 제시하지 않습니다.

이 문서는 현재 공개 상태의 사실관계를 정정하는 것으로, 제3자 데이터의 공개 이용을 허가한다는 뜻이 아닙니다.
