# 개발본과 공개 데모를 분리한 이유

## 현재 공개 상태 (2026-11-14)

- **로컬 실데이터 개발본:** SmokeSpot v3.7.41.18 — 실제 공간정보/주거인구/생활인구/사용자 현장 기록이 포함된 내부 실행 파일. **Public 저장소에 포함하지 않음**.
- **이 GitHub 저장소:** 가상 도형·가상 인구에 점수·섹터 분석 개념을 적용한 독립 실행 데모. 기능 범위는 로컬판과 다름.
- **기관 회신:** 공간정보품질관리원 문의는 회신을 받지 못한 상태. 추가 회신이 없더라도 공개 작업은 가상 데모를 기준으로 진행.

## 왜 통합 소스를 공개하지 않았나?

사용 허용과 데이터 재배포 허용은 동일한 개념이 아닐 수 있습니다. 일부 공간 데이터는 출처 표시 후 활용 가능하다는 안내를 받았지만, 다양한 기관의 건물·보도·하천·토지피복·격자통계 등 **각 자료를 가공해 GitHub/Public 웹에 다시 게시해도 되는지**는 범위별로 확인해야 합니다.

특히 로컬 `index.html`에는 실제 학교 부지 인근 등 도형의 좌표가 내장된 부분이 있어, 외부 JSON/GeoJSON을 빼는 것만으로 실제 데이터가 제거되지 않습니다. 따라서 **실제 데이터를 포함한 앱의 전체 코드를 그대로 올리지 않았습니다.**

이 결정은 특정 기관이 공개를 금지했다거나 본 프로젝트가 법률을 위반했다는 판정이 아닙니다. **명확하지 않은 권한을 임의로 허가로 간주하지 않기 위한 예방적 조치**입니다. 앞으로 이용조건이 확인되면 자료별·모듈별 공개 범위를 다시 검토할 수 있습니다.

## 무엇을 공개했나?

- 실제 서울의 좌표/지형에서 가져온 것이 아닌 별도 제작 가상 데이터
- 가상 데이터에 적용하는 보호점수·섹터·후보 탐색의 시연 코드
- 프로젝트 동기, 확인 가능한 범위의 버전별 개발 연혁, 실험의 교훈과 한계
- 공개 데모의 기능 테스트

**공개하지 않은 것:** 로컬 HTML, 실 좌표/건물·보도·학교 경계 등 상세 도형, 실제 인구 격자 자료, 특정 M1/M2 위치·원본 사진·면담 원문, 인증정보.

## 저작권·이용조건의 구분

- 제3자 자료의 사용·가공·표시·재배포 조건은 제공처별로 확인합니다.
- 개인 조사지점 및 면담·사진은 자료 사용과 별개로 공개 동의·비식별성을 고려합니다.
- 본인의 코드 라이선스 선택은 위의 제3자 데이터 공개 가능성을 자동으로 결정하지 않습니다.
- 이 공개 데모 저장소 자체에는 아직 소스 코드 라이선스를 지정하지 않았습니다.
