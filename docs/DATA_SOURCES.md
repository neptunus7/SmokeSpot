# 데이터 출처와 공개 범위

## 100% 가상 기본 데모(`/`) 데이터

| 데이터 | 생성 방식 | 실제 좌표 | 출처 |
|---|---|---|---|
| 건물·도로·보도·가상 보호 구역 | 데모를 위해 작성한 사각형·선·원 | 없음 | `js/synthetic-data.js` |
| 주거인구·생활인구 | 결정론적 합성 함수 | 없음 | `js/synthetic-data.js` |
| 보호 점수·섹터 | 공개 수식으로 위 합성 자료를 계산 | 없음 | `js/score-core.js` |

기본 데모(`/`)의 지형은 실제 서울 도형을 단순화한 것도, 원본 좌표에 노이즈를 가한 것도 아닙니다. 완전히 별개의 도식입니다. 이 설명은 `/preview/`에 적용되지 않습니다.

## 지도 기반 공개 시험판(`/preview/`) 데이터

이 별도 시험판은 실제 카카오 서울 지도 위에 표시하며, `preview/public_playgrounds.geojson` 등의 공개 파일에는 **실제 경도·위도** 및 사용자가 지도에서 직접 그린 참고 경계가 포함됩니다. 일부 시설·공원·학교 관련 공간 정보도 위치 기반으로 표시합니다. **인구 수치(100m/250m)는 가상**이며 실제 관측 인구로 해석해서는 안 됩니다. 도형의 정확성·법적 경계 여부는 미검증입니다.

이전 문서의 “공개 저장소에는 실제 좌표가 없다”는 설명은 기본 데모에만 적용됩니다. 지도 시험판에 들어 있는 공간정보는 원본·가공본별 출처/이용 조건과 공개 재배포 범위를 **추가 확인해야 합니다**. 단순 출처 표기가 모든 파일의 재배포 권한을 자동으로 보장하지 않습니다.

## 로컬 SmokeSpot 프로젝트의 자료 범주 (전체 자료는 미공개, 일부 참고 정보는 시험판에 포함)

- 국토지리정보원 등 공간정보 제공기관: 건물·도로·보도 등 공간 도형
- SGIS 2024 주거인구 100m 격자
- 서울시 2026년 10월 생활인구 250m 자료
- 환경공간정보서비스의 토지피복, 서울시 공원경계 등 별도 출처 자료
- 교육시설·버스정류소·유아시설 및 사용자가 조사한 현장 기록
- 기타 데이터 공급자별 별도 확인이 필요한 공간정보

데이터별 저작권/공공누리 이용 가능성, 재배포, 국외 제공, API 이용조건은 서로 별개의 사안입니다. 일부 자료의 출처 표기 허용 회신이 있었다는 사실만으로 위 모든 데이터의 재배포 권한을 주장하지 않습니다.

공간정보품질관리원 등 유관 기관의 미회신이 곧 허가 또는 불허는 아닙니다. 공개 중인 `/preview/`에도 실제 좌표가 포함되어 있으므로, 자료별 출처·이용 조건·재배포 가능 여부를 점검하고 **불확실한 파일은 공개 보류 또는 대체**해야 합니다. 본 문서의 정정은 그 이용을 허가하거나 적법성을 확인하는 행위가 아닙니다.

## 공개 시 유의

- 공개용 카카오 JavaScript 앱 키는 지도가 작동하는 브라우저에서 볼 수 있으므로 허용 도메인 제한 등으로 관리합니다. REST/Admin 키, 비밀 환경 파일 및 비공개 응답은 공개하지 않습니다.
- 지도 시험판의 실제 좌표·직접 등록 경계가 공개 상태라는 점을 전제로 데이터별 출처와 재배포 조건을 확인합니다.
- 현장 M1/M2의 관리인 진술은 별도 비공개 원본으로 보관하고 공개 문서에는 비식별 요약과 근거의 한계를 설명합니다.
- 지도 서비스의 캡처·재배포 조건은 별도 확인 후 시연 영상에 사용합니다.

**2026-11-15 문서 정정:** 기본 데모는 전부 가상 자료지만, `/preview/`에는 실제 좌표 기반 참고 자료가 공개되어 있습니다. 기관 회신 상황은 별도로 확인해야 하며, 포함 데이터별 재배포 권리 검토는 완료로 간주하지 않습니다.
