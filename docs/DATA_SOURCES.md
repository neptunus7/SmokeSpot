# 데이터 출처와 공개 범위

## 이 공개 저장소에 포함된 데이터

| 데이터 | 생성 방식 | 실제 좌표 | 출처 |
|---|---|---|---|
| 건물·도로·보도·가상 보호 구역 | 데모를 위해 작성한 사각형·선·원 | 없음 | `js/synthetic-data.js` |
| 주거인구·생활인구 | 결정론적 합성 함수 | 없음 | `js/synthetic-data.js` |
| 보호 점수·섹터 | 공개 수식으로 위 합성 자료를 계산 | 없음 | `js/score-core.js` |

이 파일의 지형은 실제 서울 도형을 단순화한 것도, 원본에 좌표 노이즈를 가한 것도 아닙니다. 완전히 별개의 도식입니다.

## 로컬 SmokeSpot 프로젝트의 자료 범주 (공개 저장소에는 미포함)

- 국토지리정보원 등 공간정보 제공기관: 건물·도로·보도 등 공간 도형
- SGIS 2024 주거인구 100m 격자
- 서울시 2026년 10월 생활인구 250m 자료
- 환경공간정보서비스의 토지피복, 서울시 공원경계 등 별도 출처 자료
- 교육시설·버스정류소·유아시설 및 사용자가 조사한 현장 기록
- 기타 데이터 공급자별 별도 확인이 필요한 공간정보

데이터별 저작권/공공누리 이용 가능성, 재배포, 국외 제공, API 이용조건은 서로 별개의 사안입니다. 일부 자료의 출처 표기 허용 회신이 있었다는 사실만으로 위 모든 데이터의 재배포 권한을 주장하지 않습니다.

공간정보품질관리원 등 유관 기관의 미회신이 곧 허가 또는 불허는 아닙니다. **명확한 판단 근거가 생기기 전까지 원본 GIS와 가공 상세 지형을 공개 저장소·호스팅 서비스에 올리지 않는 보수적 배포 전략**을 취합니다.

## 공개 시 유의

- 로컬 카카오 JavaScript 키, REST/Admin 키, 환경 파일, 현장 좌표 및 응답 자료는 포함하지 않습니다.
- 현장 M1/M2의 관리인 진술은 별도 비공개 원본으로 보관하고 공개 문서에는 비식별 요약과 근거의 한계를 설명합니다.
- 지도 서비스의 캡처·재배포 조건은 별도 확인 후 시연 영상에 사용합니다.

**2026-11-14 상태:** 공간정보품질관리원 문의 회신 대기. 원본 자료 및 이를 상세하게 가공한 좌표 데이터는 공개 보류. 본 가상 데모 자체에는 해당 자료가 전혀 들어있지 않습니다.
