# SmokeSpot 개발 배경과 검증 과정 (공개용 요약)

흡연자에게 이용 가능한 공간이 부족하면 비흡연자의 간접흡연 불편, 길거리 흡연, 담배꽁초 문제가 함께 발생할 수 있다. SmokeSpot은 비흡연자 보호를 우선하면서도 실제로 이용될 가능성이 있는 흡연 공간을 검토하기 위해 시작한 공공데이터 기반 입지 분석 실험 프로젝트다.

## 개발 과정

1. 건물·보도 등 공간 조건과 인구 지표로 후보지의 상대적 보호 조건을 계산하는 모델을 구성했다.
2. 금연·주의시설을 지도에 표시하고 선택 영역을 섹터로 나누어 후보지를 비교할 수 있게 했다.
3. 상가 인근 흡연 장소(M1)와 주거지 옆 공터(M2)를 현장에서 조사하고 사진·면담으로 실제 이용 현황을 살폈다.
4. M2가 주거인구 자료 충족률 기준에 미달하자 공개율 80%와 완화 실험 50%를 비교했다. 이 과정은 모델 검증을 위한 민감도 분석이지, 데이터 부족이 해결되었다는 의미는 아니다.
5. '주변 인구가 적을수록 높은 점수'가 실제 접근성과 설치 가능성까지 보장하지 않는다는 한계를 확인했다.

## 배포 전략

현재 공개 데모는 보호점수와 섹터 탐색의 핵심 아이디어만 **가상 공간·합성 인구**로 시연한다. 실제 공간정보, M1/M2 위치와 사진, 실세계 결과 점수는 공개 저장소에 포함하지 않는다. 원자료 공개조건과 현장자료 사용 동의는 별도로 점검한다.

## 향후 개선

흡연자 접근성·이용 수요와 비흡연자 보호를 분리해 평가하고, 데이터 충족률은 점수 자체와 구분해 표시하는 방향으로 발전시키고자 한다. 재떨이·부스의 시설별 차이, 운영비와 설치 가능성은 별도의 설계 단계에서 검토한다.
