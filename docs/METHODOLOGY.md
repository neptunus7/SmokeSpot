# 분석 방법 — 공개 데모

**입력은 모두 가상의 도형·인구 값**입니다. 실제 GIS·조사 사례를 재현하지 않습니다.

## 실험 대상

밀폐형 흡연부스가 아닌 **야외 개방형 간이 흡연 지점**(재떨이, 안내 표지, 개방된 작은 체류 공간)을 가정합니다. 가상 설치 지름 4m 충돌 검사의 개념은 물리적 배치에 관한 것이며 연기 확산 범위를 뜻하지 않습니다.

## 점수 P

기본 모델의 가중치는 건물 35, 보도 25, 주거인구 25, 생활인구 15입니다.

- 건물 점수 요인 `W = clamp(건물거리/50,0,1)`
- 보도 점수 요인 `F = clamp(보도거리/25,0,1)`
- 주거인구 점수 요인 `R = clamp((R_Q90 - 주변인구지표)/(R_Q90 - R_Q10),0,1)`
- 생활인구 점수 요인 `L = clamp((L_Q90 - 생활인구지표)/(L_Q90 - L_Q10),0,1)`
- `P = wW*W+wF*F+wR*R+wL*L`

**혼합 점수**에서는 건물·보도에 한해 `거리요인_mix = 0.75*거리요인_abs+0.25*거리요인_rel`을 사용합니다. `rel`은 분석 **전체 영역의 검증된 거리값 Q10~Q90**으로 계산합니다. 가까운 보도 도형이 관측되지 않은 격자는 상대점수로 임의 보너스를 주지 않습니다. 전체 영역에서 기준을 계산해 섹터를 클릭할 때 다시 변경하지 않습니다.

보호 관점 세 가지(보호 균형, 건물·보행 이격, 인구 노출 회피)는 실제 노출 저감 계수가 아니라 **가중치 민감도 비교용 시나리오**입니다.

## 합성 데이터 엔진

`js/synthetic-data.js`에 가상의 건물 사각형, 차도, 보행로, 녹지, 보호구역, 100단위 인구 중심, 250단위 24시간 인구 표본을 생성합니다. 수치나 위치는 실제로 측정된 것이 아닙니다.

위치별 건물·보도 거리는 가상 도형의 기하학적 거리로 계산합니다. 주거지 지표는 240단위 이내 셀과의 거리에 따라 `(1-d/240)^2` 가중평균을 이용합니다. 생활인구는 가장 가까운 가상 250단위 중심의 24시간 값 평균 75% + P90 25%입니다. 지역 전체 합성 표본의 Q10/Q90을 기준으로 고정 정규화합니다.

이 포팅은 실 데이터 적재와 질 관리에 해당하는 원본 앱 코드를 포함하지 않습니다. 실제 앱의 GIS 판정·공식 레이어·이용 조건은 별도로 검증해야 합니다.

## 섹터와 추천

현재 10단위 격자의 점수대([0,35), [35,50), [50,65), [65,80), [80,100])를 정의하고, 같은 점수대에 속한 4방향 인접 격자들을 연결합니다. 한 그룹은 최대 65개 격자입니다. 이는 사용자 탐색 편의에 따른 임시 기준이며 법적 구획이 아닙니다.

섹터 선택 후 해당 섹터만 5단위로 재분할해 최대 두 위치를 추천합니다. 가까운 건물과 5단위 미만인 위치는 자동 추천에서 피하며, 이것 역시 **법령에 따른 이격 기준이 아니라 연구용 우선순위 조건**입니다.

## 필수 한계

- **어느 점수도 연기 농도, 간접흡연 질병 위험, 흡연자 이용 의사, 설치 가능성의 실측값이 아닙니다.**
- 현재 인구는 가상 값이며 공개 데모에서 실세계의 주거/생활인구 민감도를 주장할 수 없습니다.
- 실제 공간정보가 없는 곳은 점수 0이 아니라 **평가 제외/미산정**으로 표시합니다.
- 실제 사용 전 지방자치단체 규정, 법령의 적용 대상, 관리 주체, 토지 사용 권한 및 현장상황을 별도로 확인해야 합니다.
