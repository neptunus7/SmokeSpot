# SmokeSpot — 원본 UI 유지형 GitHub Pages 가상 데이터 공개판 (시험본)

> **2026-11-14 · 실제 개발본 v3.7.41.18 화면 및 계산 코드 기반의 가상 데이터 전환 시험본.** 기존 단순화 데모와 다르게 로컬판과 같은 UI를 사용하지만, 정밀한 외부 지도 기능과 모든 모듈의 통합 검증을 완료한 버전은 아닙니다.

## 변경 범위

- 로컬 v3.7.41.18의 `index.html` 및 점수·공간 분석 코드를 기본으로 유지합니다.
- 학교(27개), 유아시설(19개×두 방식), 가상 공원·건물·보도·차도·하천·버스정류소 및 100/250m 통계, 보행망은 **새로 생성한 임의 자료**입니다. 모두 실제 중계동 위치와 일치하지 않습니다.
- HTML에 포함되었던 실제 출입구 보호구역 도형과 수동 보정 정류장 좌표, 실험용 보행 목표지점은 제거 또는 가상화했습니다.
- 카카오 지도는 실제 배경 지도를 보여 주지만, 덧그린 도형과 인구는 모두 가상입니다. 현장 설치 적합성 판단에 사용하면 안 됩니다.
- 브라우저 사용자 저장 데이터는 사용자의 브라우저에만 저장됩니다. 과거 로컬판의 M1/M2 실측 기록을 시연본에 포함하지 않았습니다.

## 실제 배포 전 필수 설정

1. `kakao.public.js`를 열어 `PASTE_YOUR_KAKAO_JAVASCRIPT_KEY_HERE`에 **카카오 JavaScript 앱 키만** 입력합니다. 이 앱 키는 브라우저에 노출되는 공개용 앱 키입니다. 도메인은 `https://neptunus7.github.io`로 사전 등록되어야 합니다.
2. REST API 키, 관리자 키, `kakao.local.js`, 로컬 사용 데이터, 로컬 ZIP은 절대 올리지 마세요.
3. ZIP을 풀고 `index.html`, `kakao.public.js`, 17개 가상 데이터 파일을 저장소의 `preview/` 폴더에 추가합니다. 기존 루트 공개 데모 파일은 그대로 유지합니다. 기존 README·개발 기록 파일은 삭제하지 않습니다.
4. GitHub Pages `main / (root)` 설정을 유지하고 `https://neptunus7.github.io/SmokeSpot/preview/` 주소에서 실제 휴대폰·PC에서 지도 로드·섹터 분석·점수/슬라이더·후보 0/2곳·설정 저장·수동 등록 등을 검사합니다.
