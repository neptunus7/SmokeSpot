# SmokeSpot 공개판 v10 — 통합 업로드용 (2026-11-15)

## v10 수정 항목

1. **버스정류소 28개 기본 표시 보정**: v9의 기능을 포함. 예전 브라우저 키(v8 이전)의 개별 보정값은 자동 이전하지 않음. 공식 서울시 정류소 원본 위치/분석점은 그대로 유지하며, 28개는 *지도 표시* 보정임. 버스 10m 표시 원은 보정 표시점 중심. 실제 법적 금연구역을 확정하지 않음.
2. **유아시설 19곳**: `꿈꾸리아이뜰어린이집`, `반디어린이집` 두 곳만 기본 건물 중심 +40m. 나머지 17곳 기본 건물 윤곽·위치 참고 +30m. 이전 v8의 브라우저 개별 설정은 새 v10 기본값에 혼합되지 않음. v10부터 변경한 설정은 개인 브라우저에만 저장. 화면의 잘못된 9곳/10곳 안내도 수정.
3. **을지중학교 학교 ID 02 개인 부지 보정**: 기존 27개 학교 GeoJSON을 개인 브라우저에서 불러오면 을지중을 별도로 그려 검증하고 부지 외곽 +30m를 계산. 이제 을지중 수정 도형을 개인 브라우저에 보관하고, 나중에 동일한 27개 파일을 다시 불러왔을 때 *을지중 한 곳만 자동 재적용*. 개인 GeoJSON 백업 내보내기/불러오기 가능. 브라우저 보정 기록을 지우면 원래 개인 도형으로 돌아감. 다른 26개 학교는 유지.
4. **이전 v7 수동 후보지 편집, v6 학교 절대보호 50m 개인 검증, 놀이터, 인구 가상/도로 실제 레이어** 유지 (변경 없음).

## 업로드 범위

`preview/index.html`, `preview/demo_childcare_rules.geojson`, `preview/demo_childcare_footprints.geojson` **3개 파일만 교체**합니다. ZIP 안에 API 키 파일이나 개인 학교 지적도는 없습니다. 기존 `preview/kakao.public.js`, `preview/public_playgrounds.geojson`, `preview/demo_bus_stops.geojson`은 **절대 덮어쓰지 마세요**.

## 주의 및 한계

- **학교의 법적으로 확정된 부지 경계는 공개 기본판에 포함되지 않습니다**. v10은 사용자 개인 부지 경계의 수정·보관을 개선한 버전입니다. 처음 방문하는 사용자는 교육시설 토지피복/건물 기반 참고도형만 볼 수 있습니다.
- 공개판은 실제 지형/공원 등과 가상 인구가 혼합된 데모입니다. 후보지 추천 및 보호원은 법적 설치 가능 판정이 아닙니다.
- 이번 패치는 기존 실사용 카카오 지도/후보지 통합 브라우저 테스트가 제한되어 정적 문법/데이터/오류방지 검사를 기준으로 제공하는 시험판입니다.
- 포함된 외부 공간자료의 재배포 조건은 GitHub 공개 전에 개별적으로 확인하세요. 이 ZIP은 기존 공개판에 대한 기능 수정 파일입니다.
