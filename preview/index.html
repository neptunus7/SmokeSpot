🔎 단일 250m ↔ 주변 3×3 분포 검증

선택한 격자 1개와 이웃 9개(750m×750m)를 같은 방식으로 대조해. 두 통계는 연도와 정의가 달라 정확히 일치할 필요는 없어. SGIS 인구는 완전히 포함되는 100m 격자의 공개 수치만 합산하므로 실제 거주인구 총합이 아니야.

3×3 자료를 불러오는 중이야.

이번 검증은 원본 인구를 이웃 격자에 재배분하지 않으며, 기존 후보지 점수와 추천 순위를 변경하지 않아. 실제 100m 격자 일부만 닿는 경우도 집계에서 제외했어.

📊 통합 인구영향 점수 검증 · v3.7.17 (자동 A / 수동 M / 저장)

현재 자동 후보지 탐색에도 인구 영향 배점 안에서 생활인구와 주거노출 지표를 결합해 반영해. 이 화면은 동일한 원자료를 바탕으로 수치·순위 민감도를 검토하는 곳이야.

후보지 탐색 또는 수동 지점 등록 후 기존·통합 점수 및 순위가 보여.

인구영향은 같은 주민이 두 통계에 포함될 수 있어 합산 인원수로 계산하지 않아. 3×3은 이동·체류 인구의 정답이 아닌 공간평활화 대안이고, SGIS의 비공개 100m 수치는 0명으로 바꾸지 않아. 관점을 바꾸면 같은 유효 후보풀에서 통합 점수를 다시 계산해. 통계 미공개·결측은 0으로 간주하지 않아.

*비교 주의: 완전 포함 100m 격자 총인구가 해당 250m의 03시 생활인구보다 10배 이상인 경우의 자동 검토 신호. 통계 오류율·실제 거주자 수 판정이 아님. 경계에 일부 걸친 100m 격자는 합계에서 제외하므로 250m 전체 총인구가 아니야. 통합 점수는 자동 탐색의 순위에도 적용되지만, 학교·공원·직접 등록 주의시설 등 공간적 제외 기준은 그대로 유지해.

SGIS 신청 제공 자료를 가공한 로컬 분석용 파일을 포함해. 이용 조건을 확인하기 전에는 원본 또는 가공 JSON을 공개 GitHub에 올리지 마.

🚸 주거 밀집지 → 학교급별 다중 추정 동선 · 시험판

SGIS 2024년 100m 공개 인구·가구·주택 수치로 주거 밀집 대표점을 추출하고, 유아시설·초·중·고등학교별로 보행거리가 짧은 1~2곳을 가상 목적지로 선택해. 같은 출발점의 경로 가중치는 나눠서 배분해. 실제 학생 수·배정 학교·통학량은 아님. 법적 금연구역이나 후보지 점수는 변경하지 않아.

SGIS 통계와 보행망을 준비해. 500m 안의 대표 주거지에서 학교급별 1~2곳까지 보행 경로를 비교할게.
자동 경로를 생성하면 경로 중첩 구간과 후보지의 시험 감점을 비교할 수 있어. 실제 추천 순위에는 아직 반영하지 않아.
학교별 연결 현황: 경로를 계산하면 연결된 주거 대표점 수와 연결 실패·미선택 여부를 보여줘.

대표 주거지끼리 겹치는 100m 격자는 한 곳에만 배정해. 공개된 인구·가구·주택의 밀집도를 참고하되 상대 경로 가중치는 주거 인구 제곱근이며 학생 수는 아님. 여러 학교급·목적지에 배분해 원래 가중치보다 커지지 않도록 계산해. 경로가 0개인 시설은 안전하다는 뜻이 아니라 대표점 선정·범위·보행망·목적지 선택 중 원인을 점검해야 해. 교문·출입구와 실제 학교 배정·통학량 미확인.
