# SmokeSpot — 동일 UI 공개 시연판 체크리스트

이 파일은 테스트 기록용입니다. **현재 미검증 항목을 통과했다고 주장하지 않습니다.**

- [ ] `preview/kakao.public.js`에 JavaScript 앱 키만 등록, `https://neptunus7.github.io` 도메인 허용
- [ ] Kakao Map API 활성화 상태 확인
- [ ] Pages의 `/SmokeSpot/preview/` 에서 지도가 실제로 표시되는지 확인
- [ ] 가상 자료 안내 배지가 언제나 보이는지 확인
- [ ] 원형 중심 바꾸기 → 원 표시 → 지도에서 위치 클릭
- [ ] 학교 27곳, 어린이집 19곳 등 가상 레이어 로딩
- [ ] 100m 또는 200m 섹터 선택/분석과 영역 설명
- [ ] 추천 후보 수 0/2 전환 후 재분석
- [ ] 보호시설 10m 감점 ON/OFF 및 새로고침 기본 ON
- [ ] 사용자 설정 배점 네 항목과 세 관점 초기화
- [ ] 주거 공개율 기준 변경 시 점수 재산정/미산정 변화
- [ ] 보행망 가상 경로 기능: 미실측 표시
- [ ] Chrome F12 → Console에 빨간 오류가 없는지 확인

실제 개발본과 달리 지도에 표시되는 모든 공간·인구 오버레이는 가상입니다.
