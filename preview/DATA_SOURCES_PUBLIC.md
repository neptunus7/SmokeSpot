# SmokeSpot 공개 시험판 출처·경계 수준 (2026-11-14)

- 국가기본도 차도/보도/실폭하천: 국토지리정보원, VWorld 제공, 기관의 2026-11-09 공공누리 제1유형 안내 기록. 실제 가공 GeoJSON 배포/해외 게시가 회신에 포함되는지 게시 전 최종 대조할 것.
- **건물:** 국토교통부 「연속수치지형도 건물」, VWorld, [공공데이터포털](https://www.data.go.kr/data/15125047/fileData.do) 공식 공공누리 제1유형. 주변 600m 추출/좌표변환, 1,395개 실제 윤곽. 학교 부지 자체는 아님.
- 공원: 서울시 열린데이터광장 「생활권계획 시설(공원) 공간정보」 공공누리 제1유형. 2018년 참고 공간정보이며 법적 금연경계를 인증하지 않음.
- 환경공간정보서비스: 2025 세분류 토지피복지도, 공공누리 제1유형 회신 기록, 원본/가공 내역 표시.
- **학교 27개/유아시설 19개:** 학교 중 11곳은 EGIS 2025 「교육·행정시설/운동장」 토지피복 경계에서 계산한 **실제 토지피복 참고 영역**(학교 부지 경계가 아님)을 이용하고, 나머지는 공개 가능 건물 윤곽 또는 참고원 사용. 어린이집은 13곳에서 공개 가능한 실제 건물과 사용자 선택 위치를 대조해 대응 건물 윤곽을 반영하고, 6곳은 기존 참고형상 유지. 주변 +30m 및 유아시설 40m는 시험용 분석 모델. **시설 전체 경계나 법정 금연구역이 아님**. 기존 지적 필지 도형을 복제하지 않음.
- **학교 50m:** 기존 공개판의 가상 참고원으로 유지. 검증된 출입구/절대보호구역 아님.
- 인구: 인구 관련 100m 및 250m 수치·격자 공개 시연용 가상 데이터. 실제 인구분포/실제 추천 판정 아님.
- 버스정류소: 기존 공개판의 가상 참고 위치. 서울시 공식 실측 정류소 좌표 아님.
- 사용자 놀이터: 기본값은 빈 데이터. 작성자가 로컬에서 `GeoJSON 저장` 한 파일의 권리·위치·식별정보 검토 후 업로드하면 `preview/public_playgrounds.geojson`으로 자동 로드. 원본 지도에서 따라 그린 도형은 해당 지도 제공사의 이용조건 확인 필요. 수동 등록 놀이터 주변 +3m는 모델 자체 여유구역이지 법정 이격거리가 아님.

**참고:** 국토교통부 연속지적도의 공공누리 제4유형(상업적 이용금지/변경금지) 표시와 건물 자료 제1유형을 혼동하지 말 것.


## 이번 v4 수정
- 로컬 v3.7.41.18의 **유아시설 19곳 기본 방식**(30m 9개 / 40m 10개)을 다시 적용했습니다. **꿈꾸리아이뜰어린이집·반디어린이집은 각각 선택 건물 중심 +40m가 기본값**입니다.
- 이전 브라우저에 잘못 저장된 30m 선택이 계속 남지 않도록 공개판 저장 키를 v4로 변경했습니다. 이후 사용자가 변경한 내용은 새 키에 보관됩니다.
- 학교에 사용하는 EGIS 토지피복 참고 도형은 시설 전체 부지·법정 금연구역이 아닙니다. 그 경계 +30m는 분석 시연용으로만 쓰입니다.
- 원본 연속지적도/직접 선택 학교 필지 도형은 공개 ZIP에 넣지 않았습니다.
- 기존 공개 저장소의 `public_playgrounds.geojson` 및 `kakao.public.js`는 이 업데이트 ZIP에 포함하지 않아 사용자 자료/키를 덮어쓰지 않습니다.
